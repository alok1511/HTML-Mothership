Make dashboards boardroom-ready

Open an HTML dashboard and edit it like a PowerPoint deck: text, fonts, brand colours, chart tooltips, drill-downs, tabs and help pages. Review it, test it, then export it as one HTML file.

✎EditClick, type, drag. Like slides.

🚀PublishPDF, PowerPoint, locked HTML.

Or drag & drop a file anywhere: a dashboard (.html), brand guidelines (SKILL.md / .skill), a recipe (.json) or a plugin (.js).

Quick start in six steps
  1. Open a dashboard. Click anything to select it. Double-click text to type.
  2. Layout › Add tab adds a tab (it joins your dashboard's own tabs if it has them; otherwise Layout › Tab ribbon splits the page into tabs). Add How-to/FAQ/Methodology tabs from Word, Markdown, PowerPoint, Excel or PDF files.
  3. Design › Load brand applies your colours and fonts from a skill file.
  4. Double-click a chart to set its commentary, look, pop-up and drill-down levels.
  5. 💬 Comment (Alt+2): click anything or drag a box; every comment is listed in the Comments pane. Then ✨ Prompt turns your comments into instructions for an AI assistant.
  6. Export HTML saves one file you can share, or reopen here later.
