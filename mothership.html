Mothership

Open an HTML dashboard and edit it like a PowerPoint deck: text, fonts, brand colours, chart tooltips, drill-downs, tabs and help pages. Then export it as one HTML file.

Or drag & drop a file anywhere: a dashboard (.html), brand guidelines (SKILL.md / .skill), a recipe (.json) or a plugin (.js).

  1. Open a dashboard. Click anything to select it. Double-click text to type.
  2. Layout › Tabbed layout adds a ribbon of tabs. Add How-to/FAQ/Methodology tabs from Word, Markdown, PowerPoint, Excel or PDF files.
  3. Design › Load brand applies your colours and fonts from a skill file.
  4. Double-click a chart to set its commentary, look, pop-up and drill-down levels.
  5. 💬 Comment on anything, then ✨ Prompt turns your comments into instructions for an AI assistant.
  6. Export HTML saves one file you can share, or reopen here later.
