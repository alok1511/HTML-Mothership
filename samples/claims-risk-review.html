Explore the numbers

  1. Open the Overview tab. Read the headline and the key numbers.
  2. If a filter is available, choose a region or period. Say which charts and cards should change.
  3. Hover over a bar or line to see the value and units.
  4. If the chart supports drill-down, double-click a point to see the next level. Use the breadcrumb to go back.
  5. Use Reset to return to the starting view.

If something looks different

Check the selected period, filters and reporting units. See Methodology for definitions and the data date.
